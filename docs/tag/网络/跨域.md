### 跨域的方式

- 常用的 JSONP,Proxy,CORS

### JSONP: 动态创建 script 标签,缺点是只支持 get 请求，并且很难判断请求是否失败（一般通过判断请求是否超时）
```js
// 服务端
const express = require('express');
const app = express();
const port = 3000;

app.get('/api/data', (req, res) => {
  const callback = req.query.callback;
  const data = { message: 'Hello, JSONP!' };

  if (callback) {
    // 返回 JSONP 格式的数据，注意这里拿到方法名后直接执行这个函数，前段就会直接拿到数据
    res.send(`${callback}(${JSON.stringify(data)})`);
  } else {
    res.json(data);
  }
});


// 前端
function handleResponse(data) {
  console.log('Received data:', data);
}

function makeJsonpRequest() {
  const script = document.createElement('script');
  const url = 'http://localhost:3000/api/data?callback=handleResponse';

  script.src = url;
  document.body.appendChild(script);
}

// 发起 JSONP 请求
makeJsonpRequest();
```

### Proxy 浏览器本地环境和d爱丽服务器的协议域名端口是一致的，所以没有同源策略的限制，各服务器也米有同源策略的限制
浏览器 - 代理服务器 - 目标服务器 - 代理服务器 - 浏览器
js 配置
```js
module.exports = {
  devServer: {
    proxy: {
      '/api': {
        target: 'http://example.com', // 目标服务器
        changeOrigin: true,
        pathRewrite: {
          '^/api': '' // 把标识替换为空，不至于url找不到发生404
        }
      }
    }
  }
};
```
#### [正向代理和反向代理](https://cloud.tencent.com/developer/article/1418457)
- 正向代理：通过一个代理服务器来访问目标服务器的资源，目标服务器不知道谁访问自己  
租客 - 中介 - 房东：房东不知道租客是谁，中介还可以冒充租客  
作用：提升访问速度，解决访问限制（比如跨域，访问外网）
- 反向代理：访问代理服务器，相当于访问目标服务器，浏览器不知道访问的是目标服务器  
租客 - 二房东 - 房东（妻子，儿女等）：租客不知道房东是谁，还以为是二房东  
作用：负载均衡，安全防护，提升访问速度
::: warning
1、正向代理其实是客户端的代理，帮助客户端访问其无法访问的服务器资源。反向代理则是服务器的代理，帮助服务器做负载均衡，安全防护等。  
2、正向代理一般是客户端架设的，比如在自己的机器上安装一个代理软件。而反向代理一般是服务器架设的，比如在自己的机器集群中部署一个反向代理服务器。  
3、正向代理中，服务器不知道真正的客户端到底是谁，以为访问自己的就是真实的客户端。而在反向代理中，客户端不知道真正的服务器是谁，以为自己访问的就是真实的服务  器。  
4、正向代理和反向代理的作用和目的不同。正向代理主要是用来解决访问限制问题。而反向代理则是提供负载均衡、安全防护等作用。二者均能提高访问速度。
:::

### CORS
```js
// Node.js + Express示例
const express = require('express');
const cors = require('cors');

const app = express();

const corsOptions = {
  origin: 'http://yourfrontenddomain.com', // Access-Control-Allow-Origin
  credentials: true, // Access-Control-Allow-Credentials
};

app.use(cors(corsOptions));

// 处理跨域请求的路由
app.get('/api/data', (req, res) => {
  res.cookie('myCookie', 'cookieValue', { httpOnly: true });
  res.json({ message: 'Data from server' });
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => {
  console.log(`Server is running on port ${PORT}`);
});
```
